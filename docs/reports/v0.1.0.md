## 1. Objective
Set up a repository where every later result is reproducible and every change is reviewed and tested.

## 2. What was built
- Packaging (`pyproject.toml`, optional extras), ruff lint and format, pytest.
- GitHub Actions CI on Python 3.10 and 3.12; PR template with a self-review section; issue templates
  (Task, Experiment, Bug).
- `docs/ROADMAP.md` (milestones M1-M6) and `docs/EVALUATION.md` (protocol fixed before experiments).
- `vi_rag_agent.chunking`: sentence-aware, overlapping character chunker.

## 3. Verification
- 15 unit tests; CI green on both Python versions for PR #1.
- Mutation check: accepting any boundary and removing word alignment each make a test fail.
- The coursework chunker this replaces was run on a synthetic edge case (a separator right after the
  chunk start): 4 of 495 ten-character windows were not covered by any chunk. The new chunker covers
  all of them.

## 4. Limitations
- Chunk size is measured in characters, not tokens; revisit once the embedding model is fixed (M3).
- Docker and the API are not part of this milestone.

## 5. Next
M2: evaluation harness (metrics with hand-computed tests) and a BM25 baseline on public data.
